# Responsive single page website for small business.
A clean and responsive single-page website built using Bootstrap 5. This project demonstrates modern front-end development practices, responsive layouts, and a simple user-friendly design.

## Technologies
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Features
Responsive design for desktop, tablet, and mobile devices
Bootstrap grid-based layout
Clean and simple UI
Organized single-page structure
